# Pyeonhee

A community marketplace web app built with React, Go, and AWS CDK.


## How it's built

- **Frontend (`frontend/`):** React, TypeScript, Tailwind CSS, TanStack Query
- **Backend (`backend/`):** Go (Chi)
- **Infrastructure (`infra/`):** AWS CDK in Go (Lambda, API Gateway, DynamoDB, S3, CloudFront, SES)
- **CI/CD (`.github/workflows/`):** GitHub Actions
